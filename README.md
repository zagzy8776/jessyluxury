# Jessy Luxury Fragrance — website build

A polished responsive first build for the Jessy Luxury Fragrance brand.

## Current build
- Quiet-luxury black / ivory / champagne visual system
- Responsive desktop + mobile layout
- Hero, collections, product catalogue, brand story, scent finder and footer
- Searchable product grid
- WhatsApp quick-order CTA
- No external backend required for this prototype

## Production handoff
The static prototype is intentionally dependency-free so it can be opened immediately. The production version should be migrated into Next.js/React with real product photography, the client's WhatsApp number, domain, payment gateway, product data/CMS and order handling.

## Important placeholders
- Product images are art-directed bottle mockups and must be replaced with Jessy's actual product photos.
- Product names/prices are starter data and should be confirmed against her live catalogue before launch.
- WhatsApp/social URLs are placeholders.
